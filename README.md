# Royal Match 1–20 · 网页试玩

Unity WebGL 复现试玩版，电脑浏览器打开后点击“开始试玩”。

- 拖动相邻棋子交换，点击道具使用。
- 大厅点击关卡按钮进入游戏。首次通关获得星星，返回城堡后可完成六项建造，进度自动保存。
- 大厅和关卡使用两首原包音乐，可在设置中开关。
- 关卡内 L：选择 1–20 关；R：重试；Esc：暂停。大厅设置中也可选关。
- 首次加载约 130 MB，请等待资源加载完成。
- 建议使用支持 WebGL 2 和硬件加速的 Chrome、Edge 或 Safari。

本仓库仅包含网页构建产物。游戏逻辑沿用本次构建的 Unity 工程快照，不代表已完成原客户端 1:1 验收。
